# Training for everyone

## Data
- `track`: football | hypertrophy | fat_loss | general | endurance | pregnancy | return_to_train
- `ageBand`: youth_u12 | youth_u14 | youth_u17 | adult | masters
- `level`: beginner | intermediate | advanced
- `ExercisePerformance`: effort easy|ok|hard for progression

## Safety
Youth age bands block heavy barbell / max patterns in `session-builder`.
Pregnancy track uses prenatal-safe preferences and avoids crunch/jump patterns.

## Flow
Onboarding → track + age + level → daily report → filtered dataset → cards with breaks → log effort → next day reps adjust.
